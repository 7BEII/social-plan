# flomo真实同步

范围固定为 #PD/谈恋爱 及其子标签。普通自由文字保留为经验笔记，不推测人物或评分。结构化记录使用记录类型（意向人/经验笔记/评估）和记录ID；意向值只接受用户填写0–100整数。

凭证：页面右上角齿轮可导入含token字段的本地JSON，也可粘贴Token。仅保存在当前浏览器localStorage，输入框保存后清空，页面不回显。公开配置flomo-config.js只能包含代理URL。

拉取：完整分页读取成功后才合并指定范围；保留dirty本机修改。推送：只提交dirty的新增或修改，返回真实slug才确认成功。通过内容快照防止覆盖远端改变；创建结果不明时不盲目重复创建。含附件的原笔记暂不更新，防止附件丢失。本机删除只隐藏，不删除flomo内容。

接入依据：复用PD-life/PD-rich的signed Web API协议与MD5实现，属于非官方网页接口，可能变化。既有Token经只读验证有效。Python直读筛出21条含已删除记录；代理Node只读筛出20条有效笔记。GitHub HTTPS域名的浏览器直连测试出现403和跨域拦截，不能保证直连可靠。

代理：flomo-proxy-worker.mjs在请求内转发Token，不保存凭证；只接受https://7beii.github.io来源，只有GET /read和POST/PUT /memo；读取仅返回指定标签，更新再验证归属和expected_content。wrangler.toml为可部署配置。部署后将服务地址填入flomo-config.js，网页网址保持不变。

当前状态：代理代码和本地协议验证已完成，尚未部署云端代理。需要已登录的部署平台或现有服务网址。禁止将真实Token或笔记内容写入代码、测试夹具、日志或Git。

验收：前端mock覆盖精确标签/未上传数据保护/成功回执/远端冲突/401保留；代理测试覆盖来源/标签/越界更新/409。真实验证只读，无真实写入。

## 意向人字段映射

姓名必填；层级为S/A/B/C；意向值可留空或0–100整数；偏好关键词用逗号分隔并去重；圈子/备注可选。网页自动生成记录ID。手工在flomo新增需保留#PD/谈恋爱、记录类型: 意向人、姓名字段，记录ID可省略（以memo slug生成稳定本机ID）。

## 一次私密导入

设置支持导入app=social-plan、scope=#PD/谈恋爱、memos数组的笔记JSON。先验证文件再合并；保留dirty记录，不对外发送。flomo-notes.local.json为私密数据，受*.local.json忽略，不提交Git。私密文件仅本机读取，手机需单独导入；此功能不等于跨设备自动同步。
